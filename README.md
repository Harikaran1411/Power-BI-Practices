# Power BI Practice

This repository contains my hands-on Power BI practice as part of my Data Analytics learning journey.

The repository documents practical exercises and concepts I learn while developing Power BI skills for Data Analyst roles.

---

- Power BI Desktop
- Data Loading
- Power Query
- Data Cleaning
- Data Transformation
- Data Types
- Data Modeling
- Relationships
- Data Visualization
- Charts and Graphs
- Cards and KPIs
- Filters and Slicers
- DAX
- Calculated Columns
- Measures
- Time-Based Analysis
- Dashboard Design
- Business Analysis
